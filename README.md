# Netligent Web

A modern, responsive, and dynamic website developed for **Netligent Technologies LLP**, an IT Training and Placement Institute. The website showcases the institute, its courses, services, achievements, and career opportunities through an engaging user interface.

## 🌐 Live Website

[https://netligent.com](https://netligent.com)

## 🚀 Tech Stack

### Frontend Development
- **React.js** – Component-based UI development
- **JavaScript (ES6+)** – Application logic
- **HTML5** – Website structure
- **Tailwind CSS v4** – Utility-first styling
- **React Router DOM** – Client-side routing

### Libraries & Frameworks
- **Framer Motion** – Smooth animations and transitions
- **GSAP** – Advanced animations
- **React Icons** – Icon library
- **React Helmet Async** – SEO and document metadata management
- **React Router Hash Link** – Smooth navigation to page sections
- **React Toastify** – Toast notifications
- **Formspree React** – Contact form integration

### Development Tools
- **Vite** – Fast development server and build tool
- **Vite React SSG** – Static site generation
- **ESLint** – Code quality and linting
- **Git & GitHub** – Version control

## ✨ Key Features

- Responsive and modern user interface
- Smooth animations and interactive elements
- Dynamic page navigation using React Router
- SEO-friendly page titles and meta descriptions
- Static site generation (SSG)
- Contact form integration
- Toast notifications
- Animated sections and scrolling effects
- Optimized production build

## 📂 Project Setup

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project Directory

```bash
cd netligent-web
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Development Server

```bash
npm run dev
```

The application will run locally. Open the URL provided in your terminal, usually:

```bash
http://localhost:5173
```

## 🏗️ Build for Production

To generate the production-ready build, run:

```bash
npm run build
```

The generated production files will be available in the build output directory.

## 👀 Preview Production Build

To preview the production build locally:

```bash
npm run preview
```

## 🔍 Code Quality

To check the code using ESLint:

```bash
npm run lint
```
